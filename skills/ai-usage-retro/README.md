# ai-usage-retro

## Goal

Run a weekly or monthly review of how you work with your AI agents. It reads your real conversations and your tool setup, then suggests better prompts, model choices, setup changes, and new features, and checks how last time's suggestions went.

## When to use

1. You want to know whether you are actually using AI well.
2. You want prompt or model suggestions based on your own history, not generic tips.
3. You upgraded a tool and want to know what it now makes possible.
4. You want a recurring retro on a schedule.
