# competitor-research

## Goal

Find the alternatives that actually solve the same customer job, then test whether a proposed product difference is real.

## When to use

1. You want to know whether an idea already exists or has meaningful substitutes.
2. A feature-keyword search returns many lookalikes but no clear competitors.
3. You need evidence for the competitive-edge part of an idea evaluation.

- [`SKILL.md`](SKILL.md): the search, classification, and synthesis workflow
