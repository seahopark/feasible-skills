# feasible-lab-prd

## Goal

Turn the intent behind a new feature or project into a PRD draft centered on acceptance criteria. The PM defines what to build; engineers decide how by reading the AC.

## When to use

1. You need a first PRD draft for a new feature or project.
2. You want spec, flow, and policy for a feature written down for the first planning-to-engineering discussion.
3. An existing PRD draft needs a section filled in or updated.
