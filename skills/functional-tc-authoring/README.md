# functional-tc-authoring

## Goal

Write manual-QA test-case sheets from the actual frontend code, screen by screen, with exact copy, conditions, and states in a standard 6-column format.

## When to use

1. You need test cases taken from the code, not guessed from the UI.
2. A new screen or feature needs to be added to an existing TC sheet.
3. You want to check an existing TC sheet against the code and fill gaps.
