# 시트 포맷 예시

## Legends 탭 (한 번만 정의, 전체 문서에서 재사용)

| 기호 | 유형 | 설명 |
|---|---|---|
| 🔴 | 인라인 에러 | 필드 하단에 빨간 텍스트로 에러 메시지 표시 |
| 📢 | 툴바/토스트 알림 | 화면 하단 중앙에 잠깐 떴다 자동으로 사라짐 (보통 5초), X로 닫기도 가능 |
| ⚠️ | 폼 에러 배너 | 폼 하단에 아이콘+빨간 텍스트로 서버 에러 인라인 표시 |
| 🚫 | 버튼 비활성화 | 조건 미충족 시 버튼 자체가 disabled |
| ➡️ | 페이지 이동 | 성공 시 다른 경로로 리다이렉트 |

이모지가 안 맞는 경우 자유 텍스트를 쓴다: `화면 상태 변경`, `모달 오픈`, `모달 닫힘`, `목록 갱신` 등.

## 탭 안 섹션 구조

한 기능 영역 탭 안에서, 논리적 하위 영역마다 아래 패턴을 반복한다:

```
[빈 행]
["9. 프로젝트 목록 — 정렬/필터/검색"]                                    ← 섹션 제목 (번호 매기기)
["All Projects > Projects/Drafts 탭 상단 툴바. 필터 4종, 검색창"]        ← 한 줄 설명 (어떤 컴포넌트/화면인지)
["#", "테스트 케이스", "사전 조건", "실행 액션", "기대 피드백", "피드백 유형"]  ← 헤더 (섹션마다 반복)
["L-01", "정렬 컨트롤 없음 (고정 순서)", "Projects 탭 진입", "목록 확인",
 "별도 정렬 UI 없음, 항상 \"최근 수정순(최신)\" 고정 정렬", "화면 상태 변경"]
["L-02", ...]
...
```

## ID 접두사 예시 (섹션 주제별로 즉석 작명, 문서 전체에서 유일해야 함)

- `L-` 목록/리스트 화면
- `BA-` 벌크 액션(bulk actions)
- `RA-` 행별 액션(row actions)
- `CB-` 생성 버튼(create button)
- `AB-` / `PB-` 담당자별/상태별 보드 뷰
- `FC-` / `FL-` / `FD-` / `FH-` 폴더 관련 하위 영역들(카드/전체목록/상세/헤더)
- `N-` 알림 토스트
- 다른 기능 영역이면 그 영역에 맞는 새 접두사(`QT-`, `QF-`, `QE-` 등)를 또 만들면 됨 — 전역으로 고정된 접두사 세트는 없음, 섹션 스코프 안에서만 의미를 가지면 됨

## 섹션 설명 행에 경고를 넣는 예시 (데모/목업 코드일 때)

```
["12. Flagged Q/A 검토 모달 (데모 전용, 실제 저장 안 됨)"]
["⚠️ 코드 자체 주석에 \"No API calls are made\"로 명시된 정적 데모 UI.
 아래 케이스는 로컬 화면 상태만 검증하는 용도 — 새로고침하면 전부 리셋됨.
 실제 저장/영속성 버그로 오인하지 말 것."]
```
