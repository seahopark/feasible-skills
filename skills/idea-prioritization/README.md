# idea-prioritization

## Goal

Decide what to work on next among several ideas: explore the problem first, filter candidates through four qualitative checks (market vs. problem, competitive edge, scalability, founder drive), then use ICE or RICE only when the inputs support scoring.

## When to use

1. You have a pile of unstarted ideas or backlog items and need to pick what to do first.
2. You have explored a single idea and want a structured "is this worth doing?" check.
3. You need to explain a priority call with evidence, using numbers only when supported.
