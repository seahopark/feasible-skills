# idea-prioritization

## Goal

Decide what to work on next among several ideas: filter them through four qualitative checks (market vs. problem, competitive edge, scalability, founder drive), then rank the survivors with ICE or RICE.

## When to use

1. You have a pile of unstarted ideas or backlog items and need to pick what to do first.
2. You want a structured "is this worth doing?" check on a single new idea.
3. You need to back a priority call with numbers instead of gut feel.
