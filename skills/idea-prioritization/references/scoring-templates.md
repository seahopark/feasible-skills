# ICE / RICE Scoring Reference

## ICE (Impact × Confidence × Ease)
Fast calls, when effort doesn't vary much between candidates.

| Axis | 1 | 3 | 5 |
|---|---|---|---|
| Impact | Barely moves the needle | Noticeable improvement | Game-changing |
| Confidence | Pure guess | Some supporting evidence | Backed by data / precedent |
| Ease | Takes months+ | Takes weeks | Doable in days to a week |

**Total = Impact × Confidence × Ease** (max 125)

| Idea | Impact | Confidence | Ease | Total |
|---|---|---|---|---|
| | | | | |

## RICE (Reach × Impact × Confidence ÷ Effort)
When effort varies a lot between candidates (dividing by Effort captures "return per unit of work").

| Field | Guidance |
|---|---|
| Reach | People/transactions affected in a given period (actual number, or a 1–5 relative score) |
| Impact | None (0.25) / Low (0.5) / Medium (1) / High (2) / Massive (3) |
| Confidence | Low (50%) / Medium (80%) / High (100%) |
| Effort | Person-months, or a 1–5 relative score |

**Total = (Reach × Impact × Confidence) ÷ Effort**

| Idea | Reach | Impact | Confidence | Effort | Total |
|---|---|---|---|---|---|
| | | | | | |

## Usage notes
- These scores are for **relative comparison** between candidates in the same session — the absolute number carries no meaning on its own.
- One evaluator applying one consistent standard across all candidates in a single pass is what makes the comparison meaningful. If the bar shifts candidate to candidate, the scores stop being comparable.
