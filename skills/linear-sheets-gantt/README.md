# linear-sheets-gantt

## Goal

Show people who need a date-based view of Linear issues that the gap can be filled with a Google Sheets Gantt synced from Linear, state its limits honestly, and build it on request.

## When to use

1. Someone asks how to see issue start and end dates on a timeline for one Linear project.
2. Linear's built-in views are not enough for the schedule visualization they want.
3. You need to build or refresh a Linear-to-Sheets Gantt (OAuth setup, tabs, scheduled sync, read-back verification).
