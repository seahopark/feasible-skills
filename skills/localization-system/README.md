# localization-system

## Goal

Design a multi-language UI system (structure, rules, glossary, key convention) and run translation and review inside it consistently.

## When to use

1. You are setting up localization for a product and need the glossary, per-language rules, and key naming convention.
2. You want to translate or review UI strings with placeholders and tags preserved.
3. You want a translation bot or agent with translate, review, and question modes plus a five-item review checklist.

- [`SKILL.md`](SKILL.md): the full procedure the agent follows
