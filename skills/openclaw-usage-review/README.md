# openclaw-usage-review

## Goal

Review how you actually used OpenClaw and suggest features and settings to try, explain what became usable after an upgrade, and keep settings tied to written reasons.

## When to use

1. You self-host OpenClaw and suspect you use only a fraction of it.
2. You just upgraded and want to know what is new for you.
3. You want a weekly usage review automation.
