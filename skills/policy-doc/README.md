# policy-doc

## Goal

Create and maintain service policy documents in Markdown, converted from a PRD or TC sheet and checked against the real code and issue tracker when available.

## When to use

1. You need a policy doc or UX spec for a service.
2. You want to turn a PRD or TC spreadsheet into a policy doc.
3. Planning and implementation have drifted and the policy doc needs to match the code again.
