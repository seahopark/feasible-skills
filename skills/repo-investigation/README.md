# repo-investigation

## Goal

Determine both how far a feature is implemented and whether a specific user can use it in a specific environment now.

## When to use

1. You need to know whether a feature is actually available in production or staging.
2. A feature spans frontend, API, worker, or data repositories.
3. Code exists, but deployment, flags, permissions, or required integrations may block use.

## Files

- [`SKILL.md`](SKILL.md): the evidence chain, environment-availability decision table, and report shape
