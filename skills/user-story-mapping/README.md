# user-story-mapping

## Goal

Build a user story map that lays out user activities, steps, and tasks in journey order and slices them into releases (Jeff Patton's method).

## When to use

1. You are planning an MVP or release scope around the user's workflow.
2. Your backlog is a flat list and you want to see it as a journey.
3. Product, design, and engineering need a shared picture of what the user does.
