# ux-writing-brand-voice

## Goal

Write and review product UI copy against a written set of guidelines, and define a brand voice with the team when none exists.

## When to use

1. You are writing or editing buttons, errors, notifications, or empty-state text and want it plain, warm, and consistent.
2. You want existing copy reviewed in a before/after/reason table.
3. A product has no voice document and you need a team workshop procedure (benchmark, interviews, core values, persona, channel messages).

## Files

- [`SKILL.md`](SKILL.md): the full procedure the agent follows

## Note

The seven baseline guidelines are written for Korean UI copy, so examples are Korean strings with English glosses. The voice-definition procedure is language-independent.
